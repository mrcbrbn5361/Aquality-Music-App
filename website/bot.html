Discord Bot & RPC Sistemi

Aquality Music'te dinlediğiniz şarkıyı Discord profilinizde zengin durum (RPC) olarak sergileyin, sunucunuz için Canvas kartlı Discord botunu kurun veya Yerel REST API ile entegrasyonlar geliştirin.

Bot Kurulum Rehberi Yerel REST API GitHub Kaynak Kodları ↗

1. Discord Rich Presence (RPC)

Masaüstü oynatıcı çalışırken Discord uygulamanıza otomatik bağlanır ve çalan müziği anlık yayınlar.

Otomatik IPC Bağlantısı

Masaüstü uygulamasını açtığınız anda Discord IPC soketi (\\?\pipe\discord-ipc-0) üzerinden yerel Discord istemcinizle el sıkışılır. Kullanıcı adı veya şifre girmenize gerek kalmaz.

  • Aktivite Türü: Dinliyor (Listening)
  • Zaman Damgası: Gerçek zamanlı dinamik geri sayım çubuğu
  • Görsel Detaylar: Yüksek çözünürlüklü albüm kapağı ve Aquality rozeti
  • Harmonic Desteği: Çift Application ID desteği ile tam uyum

Application ID Bilgileri

Kendi Discord botunuzu veya RPC profilinizi yapılandırırken kullanabileceğiniz doğrulanmış Discord Application ID'leri:

Application ID Tanımları
// Aquality Music Resmi RPC ID
APPLICATION_ID = "1547602880427724841";

// Harmonic Teması RPC ID
HARMONIC_APP_ID = "1545832861435830432";

🛡️ Güvenlik & İzolasyon: Bot yalnızca resmi Aquality sunucusunda çalışır, dış sunuculardan gelen istekleri reddeder. Spam ve aşırı yüklenmeyi önlemek için kullanıcı bazlı 3.5 saniye bekleme süresi (anti-spam cooldown) ve kanal izin doğrulama filtreleri aktiftir.

🎵 Sıfır Token, Tam Otomatik Senkronizasyon

Kullanıcıların herhangi bir bot oluşturmasına veya uygulamaya token girmesine gerek yoktur:

  • Masaüstü RPC Entegrasyonu: Aquality Music masaüstünde çalarken Discord durumunuz (Listening) otomatik güncellenir.
  • İki Sıralı İnteraktif Butonlar: Kartın altında doğrudan şarkı bağlantısı ve iTunes API destekli 3 popüler öneri butonu yer alır.
  • Gömülü Afiş Kartı: Koyu cam tasarımlı, canlı neon yeşili süre göstergeli yüksek çözünürlüklü afiş görseli üretilir.

3. Yerel REST API Sunucusu (Port 9863)

Aquality Music masaüstü uygulaması açıldığında yerel makinenizde hafif bir HTTP REST API ayağa kaldırır.

GET http://127.0.0.1:9863/api/v1/state
Çalan parça, sanatçı, süre sayaçları, ilerleme oranı ve sıradaki önerileri döner.
GET http://127.0.0.1:9863/query
Geriye dönük uyumluluk için /api/v1/state ile aynı JSON verisini döndüren kısayol.
GET http://127.0.0.1:9863/api/v1/health
REST API sunucusunun aktif ve dinlemede olduğunu doğrulamak için sağlık kontrolü.

4. Bot Kurulum ve Çalıştırma Rehberi

Aquality Discord botunu kendi Discord sunucunuzda 5 dakikada yayına alın.

1

Bot Dizinine Geçin

Terminalinizde scripts/discord-bot klasörüne gidin.

2

Paketleri Yükleyin

npm install komutu ile discord.js ve canvas paketlerini kurun.

3

Token Belirleyin

.env dosyasında botunuzun DISCORD_TOKEN değerini tanımlayın.

4

Başlatın

node index.js komutuyla botu sunucunuzda aktif hale getirin.

Önemli: Discord Developer Portal Intent Ayarları

Botun sunucudaki kullanıcıların müzik dinleme durumunu ve komutlarını okuyabilmesi için Developer Portal üzerinden şu 3 iznin açık olması zorunludur:

✅ PRESENCE INTENT (Aktif)
✅ SERVER MEMBERS INTENT (Aktif)
✅ MESSAGE CONTENT INTENT (Aktif)
